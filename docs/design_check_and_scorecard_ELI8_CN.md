# 设计检查与 run 成绩单：掰开揉碎讲（给 Daqian，2026-11-05）

一句话版本：**设计检查**看的是「分组表」有没有坑，还没碰任何数据；**run 成绩单**看的是「每一次上机」有没有跑坏，用的是 DIA-NN 自己记的体检单。两个都在你看任何差异结果之前完成。

---

## A 部分：设计检查

### A1 它只看一张表
就是你填的注释表。它只用五样东西：run 的名字、组别（group）、动物或供体（subject_id）、批次（batch）、上样顺序（run_order）。它不看强度、不看肽段、不看任何谱图。所以它快得像翻一页纸，也只能回答「这张表本身合不合理」。

### A2 先把「陪跑的」挑出来
有些 run 不是实验样品，是 pooled QC、HeLa 标准品、空白。它们像赛跑时陪跑的配速员，不参加排名。平台按名字找它们：组名或样品名里有 pool、QC、HeLa、standard、blank 的，先拿出来放一边，后面所有检查只用真正的实验 run。

### A3 数人头
每个组有几个 run、几只动物、出现过哪些批次、上样顺序从几号到几号。组里只有 1 或 2 个 run 会被提醒：两个人也能比身高，但看不出「正常的身高差距是多大」，统计上叫估不出离散度。

### A4 批次和组别有没有「绑在一起」
这是设计检查最重要的一步。先讲比喻。

A 班全在周一考试，B 班全在周二考试。B 班平均分高了 5 分。是 B 班更聪明，还是周二的卷子更简单？**没法知道**。因为「班级」和「考试日」完全重叠，两种解释给出一模一样的成绩表。这就叫**混杂（confounded）**。

反过来，如果 A 班和 B 班各有一半人周一考、一半人周二考，就能把「周几考」的影响算出来再扣掉，剩下的才是班级差异。这叫**交叉（crossed）**。

平台的做法很朴素，不做任何统计检验：
1. 画一张「组 × 批次」的人数表。
2. 拿任意两个组出来，看它们各自出现过哪些批次。
   - 两组没有任何共同批次：**confounded**，红色。
   - 两组都只在同一个批次里：**same single batch**，绿色，这一对比较里批次根本没变化。
   - 其他情况：**crossed**，绿色，批次可以放进模型估计并扣除。
3. 把所有 confounded 的对子合并成一条红色消息。

为什么不用检验？因为这是结构问题，不是概率问题。两组没有共同批次时，无论样本再多、模型再好，批次效应和组别效应在数学上就是同一个数，谁也拆不开。能做的只有两件事：报告时把这种对比标成「supportive」，或者重新做实验让批次交叉。

一个小例子：

| run | 组 | 批次 |
|---|---|---|
| r1, r2, r3, r4 | A | X |
| r5, r6, r7, r8 | B | Y |

A 只在 X，B 只在 Y，没有共同批次，confounded。换成 A 在 X、X、Y、Y，B 在 X、X、Y、Y，就是 crossed。你的论文数据正是前一种：CNT 和 CNTA 都在 Date_0721，LIM 和 LIMA 都在 Date_0828，所以四个跨批次对比全部 confounded；而 CNT 对 CNTA、LIM 对 LIMA 各自落在同一批次内，是 same single batch。

### A5 上样顺序有没有「排成一队」
仪器像一个慢慢变松的弹簧，一个序列从头到尾会漂移。如果 A 组全排在前面跑、B 组全排在后面跑，漂移就会伪装成组间差异，而且每个蛋白都往同一个方向偏，看起来还非常「显著」。

平台把每个 run 的上样序号按组做一个 Kruskal-Wallis 检验。它的想法只有一句话：把所有序号从小到大排名次，看每个组拿到的名次是「混在一起」还是「一边倒」。8 个 run 的玩具例子：

- A 组拿 1、2、3、4 号，B 组拿 5、6、7、8 号：一边倒，p = 0.021，橙色警告「顺序分块」。
- A 组拿 1、3、5、7 号，B 组拿 2、4、6、8 号：混在一起，p = 0.56，绿色「顺序交叉」。

没有 run_order 列时，它只能提醒：漂移图会按注释表的行序来画。

### A6 能不能配对
同一只动物的两只眼，一只做处理一只做对照，就能「自己和自己比」，把动物之间的差异整个扣掉，这是配对设计的全部意义。平台数每个 subject_id 在几个组里出现：有 subject 跨两个组，就说「可以配对」；每个 subject 都只在一个组，就说「只能非配对」。同一个 subject 在同一组出现两次以上，会提醒这可能是技术重复，配对分析会跳过它们。

### A7 有没有秤砣
pooled QC 是把所有样品各取一点混在一起、在序列里反复进样的那个「秤砣」。它本身没有生物差异，所以它每次称出来的差别全是技术误差。有它，才能直接量出技术精度和漂移。平台认出了就列出名字和它们在序列里的位置；没认出就橙色提醒，并说明 QC 页会改用「同一动物双眼一致性」和漂移图来代替，这是弱替代，因为双眼之间有真实的生物差异。

### A8 颜色
绿色 ok 是「这项没问题」；蓝色 info 是「表里缺一列，查不了」；橙色 warn 是「有隐患，看着办」；红色 danger 是「结构性问题，统计救不了」。

## B 部分：run 成绩单

### B1 它看什么
DIA-NN 搜库时给每个 run 写了一张体检单，就是 `report.stats.tsv`。平台取 14 项：鉴定到的 precursor 数和蛋白数；总定量、MS1 信号、MS2 信号；峰宽按扫描数、峰宽按分钟；MS1 和 MS2 质量误差；保留时间偏差；归一化不稳定性；漏切率；平均肽段长度；平均电荷。每一项对应一种具体的故障，QC 讲义里逐条写了为什么看它。成绩单回答的只是一个问题：**这个 run 和它的同伴比，是不是明显不一样？**

### B2 「同伴」是谁：按批次分层
身高要和同龄人比，不能把一年级和六年级放一起比。两个批次的 run 本来就系统性不同，混在一起比，正常的批次差异会把尺子撑大，真正的坏 run 反而藏起来。所以：注释表有 batch 列、批次不止一个、而且每个批次至少 4 个 run 时，每个 run 只和**同批次**的 run 比；否则所有 run 一起比。4 是下限，3 个点算不出有意义的中位数和离散度。

### B3 尺子怎么做：中位数和 MAD
假设 7 个 run 的鉴定数（千）是 43、61、63、64、65、66、67。

- **中位数**：从小到大排好，取中间那个，这里是 64。它不怕离群点，因为 43 再小也只占一个位置。
- **MAD**：每个数和中位数的距离是 21、3、1、0、1、2、3，再取这些距离的中位数，得 2；乘上 1.4826，得 2.97。乘这个常数是为了让它和正态分布的标准差一个尺度。可以把 MAD 理解成「大家平常离中位数有多远」，而且它同样不怕离群点。
- **上下限**：中位数 ± 3 个 MAD。3 个 MAD 大致等于 3 个标准差，这是 QC 里公认的「明显离群」尺度。

为什么不用平均数和标准差？因为离群点会自己把尺子撑大。同一组数的平均数是 61.3，标准差 8.3，平均数减 3 倍标准差是 36.4，于是 43 这个明显掉队的 run 反而「合格」了。中位数和 MAD 不上这个当。

### B4 只看坏的那一边
有些指标只有一边算坏：鉴定数、峰宽按扫描数只怕**低**；峰宽按分钟、质量误差、保留时间偏差、归一化不稳定性、漏切率只怕**高**。这些指标只设一条限，另一边再极端也不标。信号量、肽段长度、电荷两边都怕，设两条限。

### B5 两个特例
- **鉴定数**不用 MAD，用「低于同批次中位数的 70%」。鉴定数的分布常常是偏的，批次内波动又小，MAD 会把限定得太窄、误报一片；70% 是经验值。上面的例子里 70% × 64 = 44.8，43 被标记。
- **漏切率**除了 MAD 还有一条绝对线 0.25。但它只在该批次的中位数本身低于 0.25 时才启用。如果整批都高于 0.25，说明是全队列消化不完全，平台改报一条「全队列」的提示，而不是把每个 run 都标红。公开数据的中位数是 0.33，就是这种情况。

### B6 信号量先取对数
总定量、MS1 信号、MS2 信号这三项的数值动辄 10 的 11 次方，而且分布右偏。先取 log10 再算中位数和 MAD，等于按「倍数」而不是按「差值」来比。例子：7 个 run 的 MS1 信号是 5.2、5.5、6.1、4.9、5.8、1.2、6.3（单位 10 的 11 次方），取对数后中位数 11.74、MAD 0.067，下限换算回来是 3.47，于是 1.2 那个 run 被标记。

### B7 标记怎么数
一个 run 在一个指标上越线就得一个标记。把 14 项的标记加起来，**两项以上**的 run 进「two or more」名单，这就是 QC 页瓷砖和 PDF 报告判定表里的数字。只有一项的 run 列在旁边，提醒你看一眼。图上灰线是同批次的中位数，红色虚线是上下限，红圈是被标记的点，旁边写着 run 名。

### B8 「整批都偏」和「一个 run 偏」是两回事
B3 到 B7 找的是单个掉队的 run。但还有另一种情况：整个批次的肽段都偏长、电荷都偏高，批次里每个 run 都「正常」，批次之间却系统不同。这种情况成绩单单独报告，叫 systematic differences：对每个指标按批次、按组各做一次 Kruskal-Wallis，p 小于 0.01 的列出来，并附上各批次的中位数。你的数据里肽段长度、电荷、保留时间偏差、峰宽都按批次系统不同，这是两批消化与色谱条件不同的直接证据。因为组别和批次混杂，按组检验会把同一效应再报一次，报告里也写明了。

### B9 拿到标记以后做什么
1. 先看绝对值：标记只说明「和同伴不一样」，不说明「坏到不能用」。鉴定数掉了 2% 和掉了 40% 都可能被标，意义完全不同。
2. 再看三层是否指向同一个 run：成绩单两项以上、marker 面板有异常、队列 QC 两项以上，三层同时指向，排除的理由就硬。
3. 排除决定在看差异分析之前做，写进运行记录；之后不因为「结果不好看」回头改。

## 一页总表

| 步骤 | 它问的问题 | 规则 |
|---|---|---|
| 设计 A2 | 哪些 run 是陪跑的 | 名字含 pool / QC / HeLa / standard / blank |
| 设计 A4 | 批次和组别绑在一起吗 | 两组无共同批次 = confounded；都在同一批次 = same single batch；其余 = crossed |
| 设计 A5 | 上样顺序分块吗 | 序号按组做 Kruskal-Wallis，p < 0.05 警告 |
| 设计 A6 | 能配对吗 | 同一 subject 在两组都有 run |
| 设计 A7 | 有秤砣吗 | 认出 pooled QC 就报位置，没有就警告 |
| 成绩单 B2 | 和谁比 | 同批次，每批至少 4 个 run，否则全体 |
| 成绩单 B3 | 尺子多长 | 中位数 ± 3 MAD，MAD 乘 1.4826 |
| 成绩单 B4 | 哪边算坏 | 按指标的关注方向设一条或两条限 |
| 成绩单 B5 | 特例 | 鉴定数低于中位数 70%；漏切率 0.25 只在批次中位数低于 0.25 时启用 |
| 成绩单 B6 | 信号量 | 先取 log10 |
| 成绩单 B7 | 谁是候选 | 两项以上标记 |
| 成绩单 B8 | 整批偏了吗 | 每个指标按批次、按组做 Kruskal-Wallis，p < 0.01 列出 |
